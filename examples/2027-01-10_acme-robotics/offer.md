# Stage Développeur Full-Stack & IA — Acme Robotics (fictional example)

Lyon · Stage de 4 à 6 mois à partir de février 2027 · Hybride

## Missions
- Développer des API REST en Node.js pour notre plateforme de supervision de robots.
- Construire des interfaces React pour les opérateurs.
- Prototyper des fonctionnalités basées sur des LLM (résumés d'incidents, assistant).
- Écrire des tests et participer aux revues de code.

## Profil
- Élève-ingénieur en informatique (Bac+4/5).
- Maîtrise de JavaScript/TypeScript, Node.js et React (requis).
- Notions de Python (requis).
- Expérience avec une API de LLM (un plus).
- Docker, CI/CD (un plus).
- Anglais professionnel.

Candidature : CV + lettre de motivation (facultative).
